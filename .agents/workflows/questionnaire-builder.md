# Questionnaire Builder Workflow

This workflow describes the end-to-end process of creating, validating, and publishing clinical research questionnaires using the MusB Command Center.

## 1. Project Initiation
1. Navigate to the **Coordinator Dashboard** and select **Questionnaire Builder**.
2. Select the **Target Study** from the protocol dropdown in the header to associate the instrument with a specific clinical mission.

## 2. Instrument Orchestration
1. Use the **Protocol Map (Left Sidebar)** to add research sections.
2. Click **Add Field** within a section to append a new data node.
3. In the **Architectural Canvas (Center)**, define the question label and interact with the node.

## 3. Behavioral Logic & Scoring
1. Select a node to open the **Question Intelligence (Right Sidebar)**.
2. Configure **Field Logic** (Mandatory vs. Optional) and **Branching** rules.
3. Open the **Scoring Engine** to define algebraic formulas for real-time endpoint calculation.
4. **Synchronize** the engine to ensure logic integrity.

## 4. Validation & Quality Control
1. Toggle the **Preview Mode (Desktop/Mobile)** to verify the participant experience.
2. Review the **AI Integrity Scan** in the Intelligence panel for GCP compliance and validation strength.
3. Save as **Draft** during the iterative refinement phase.

## 5. Deployment
1. Click **Publish & Assign** to finalize the instrument.
2. Once published, the questionnaire is automatically assigned to the linked study and becomes available for participant data entry via the Electronic Case Report Form (eCRF) system.
3. Review existing instruments in the **My Questionnaires** registry for version control and lifecycle management.
